# 12306 车次列表页 跨浏览器兼容性测试报告

## 测试环境
- 桌面浏览器：Chrome 120、Firefox 121、Edge 120
- 操作系统：Windows 11、DPI 125%、显示比例 100%
- 预览地址：`http://localhost:5173/tickets`

## 结果摘要
- 渲染一致性：SVG Logo、表头蓝底白字、日期条、按钮圆角与色值在三浏览器均一致
- 字体回退：若缺少 Tahoma/宋体，使用系统 Sans 回退，不影响版式比例
- 响应式：≤992px 保留横向滚动查看完整表格；Logo 使用 `clamp` 保持清晰
- 交互：排序按钮、查询/预订按钮的 hover/active 状态在三浏览器一致

## 详细检查项
- SVG 矢量渲染：通过（抗锯齿正常）
- Flex/Grid 布局：通过（列宽与断点一致）
- Input/Select 原生控件：通过（边框、文字对齐一致）
- 无障碍基础：Logo 可键盘触发返回首页；表格区域设置 `role="table"`，通过

## 建议
- 若需更严格的像素级一致性，建议固定中文与数字字形为路径（AI 转曲）并将表头文字转为 SVG 文本以避免平台差异；当前实现已满足屏幕端复刻与日常使用。
